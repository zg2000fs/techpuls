DeepSeek je osvježio V4.1-Flash

DeepSeek je osvježio V4.1-Flash-1017 i model sad bolje radi u programiranju te s AI agentima, uz manje vremena i manje izlaznih tokena. Na DeepSWE v1.1 postiže 77 bodova, ispred prethodne verzije i nekih rivala, ali Claude Opus 5 i dalje ostaje jači na više drugih benchmarkova. Uz to, DeepSeek je otvorio Search API i Fetch API vanjskim developerima za agente i RAG sustave.

DeepSeek je objavio ažuriranje V4.1-Flash-1017. Model se sada bolje snalazi u zadacima programiranja i u radu s AI agentima, a pritom troši manje vremena i generira manje izlaznih tokena.

Težine modela objavljene su na Hugging Faceu pod licencom MIT. Isprobati ga možete putem web stranice, aplikacije DeepSeek i preko API-ja.

Benchmarkovi

Prema rezultatima koje navodi DeepSeek, na testu DeepSWE v1.1 nova je verzija ostvarila 77 bodova, naspram 74,2 koliko je imala prethodna V4.1-Flash. Taj je rezultat viši i od onoga koji su ostvarili Claude Opus 5 (74) i GPT-5.6-Sol (73).

Istodobno, Claude Opus 5 je ispred osvježene Flash verzije na testovima Terminal-Bench 4.0 (51,8), ProgramBench (37,0 naspram 29,1) i NL2Repo-Bench (75,3 naspram 68,2). Na HLE testu bez alata Opus 5 također ima bolji rezultat: 56,3 naspram 42,6 za DeepSeek.

Terminal-Bench 4.0 testiran je u okruženju Claude Code, a DeepSWE v1.1 uz korištenje Mini-SWE-V2.

Search i Fetch API sada su dostupni developerima

Posebno ažuriranje odnosi se na alate za rad s webom. DeepSeek je otvorio Search API i Fetch API na temelju vlastitog search enginea.

Search API prima upit za pretraživanje i vraća strukturirane rezultate. Fetch API dohvaća sadržaj konkretne web-stranice i vraća ga u Markdown formatu. Oba će alata biti korisna za izradu AI agenata i RAG sustava.

Cijena svakog API-ja iznosi 0,75 USD za 1000 uspješnih zahtjeva. Naplaćuju se samo zahtjevi koji su vratili rezultat: prazni rezultati, greške i timeouti ne naplaćuju se.

Pozivi Search i Fetch kroz DeepSeek Harness, Claude Code i Codex zasad su besplatni. Prema dokumentaciji, naplata tih instrumentalnih poziva trebala bi početi 1. studenoga.
