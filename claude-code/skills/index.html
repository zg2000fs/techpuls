Claude Code: skills, vlastite naredbe

Skill je folder s fileom SKILL.md u kojem su upute za Claudea. Napraviš ga kad stalno lijepiš iste upute ili kontrolni popis. Tijelo skilla učitava se tek kad zatreba, pa troši malo konteksta.

1. Gdje živi skill

Osobni skillovi (rade u svim tvojim projektima): C:\Users\<tvoje-ime>\.claude\skills\<ime-skilla>\SKILL.md. Skillovi projekta (samo u tom repozitoriju, dijele se s timom): <projekt>\.claude\skills\<ime-skilla>\SKILL.md.

2. Napravi folder

U PowerShellu napravi folder za osobni skill:

mkdir $HOME\.claude\skills\summarize-changes

3. Napiši SKILL.md

Spremi file SKILL.md u taj folder. Name je ime naredbe (ako ga izostaviš, koristi se ime foldera), description govori Claudeu kad skill treba upotrijebiti. Ispod zaglavlja su upute.

---
name: summarize-changes
description: Summarizes uncommitted changes and flags anything risky. Use when the user asks what changed or wants a commit message.
---

Summarize the uncommitted changes in your git repository in two or three
bullet points, then list any risks you notice, such as missing error handling,
hardcoded values, or tests that need updating.

4. Pozovi ga

Pokreni claude i upiši ime skilla kao slash naredbu. Ili pitaj nešto što odgovara opisu (npr. što sam promijenio?), pa će ga Claude sam učitati.

Isprobaj Claude: tjedan dana Pro besplatno (partnerska poveznica)
/summarize-changes
Isprobaj Claude: tjedan dana Pro besplatno (partnerska poveznica: ako se preko nje pretplatiš, TechPuls može dobiti nagradu, a tebe to ne košta ništa)
