Claude Code za početnike

Idi redom, od #1. Vodiči korak po korak, s Windowsa, s naredbama koje možeš kopirati jednim klikom. Za svaki postoji i kratki video na našem YouTube kanalu.

Isprobaj Claude: tjedan dana Pro besplatno (partnerska poveznica)
  1. #1 Claude Code na Windowsu: instalacija korak po korak

    Claude Code je Anthropicov alat koji radi u tekstualnom prozoru (terminalu) i može čitati, mijenjati i pokretati kod u tvom projektu. Ovaj vodič vodi te kroz instalaciju na Windowsu, čak i ako nikad nisi koristio terminal.

  2. #2 Claude Code: file CLAUDE.md i naredba /init

    Ako Claudeu u svakoj sesiji iznova objašnjavaš kako se gradi tvoj projekt, postoji jednokratno rješenje: file CLAUDE.md.

  3. #3 Claude Code: načini rada i dozvole

    Claude Code ima više načina rada koji određuju što smije napraviti bez tvog odobrenja. Za početak ostani u ručnom načinu, a plan mode koristi za veće zadatke.

  4. #4 Claude Code: slash naredbe

    Slash naredbe upisuješ unutar Claude Codea, na početku poruke. Ovdje su one koje ćeš koristiti najčešće.

  5. #5 Claude Code: skills, vlastite naredbe

    Skill je folder s fileom SKILL.md u kojem su upute za Claudea. Napraviš ga kad stalno lijepiš iste upute ili kontrolni popis. Tijelo skilla učitava se tek kad zatreba, pa troši malo konteksta.

  6. #6 Claude Code: MCP, spajanje vanjskih alata

    MCP (Model Context Protocol) je otvoreni standard koji Claude Code spaja s vanjskim alatima i izvorima podataka, npr. alatima za zadatke, bazama i nadzornim pločama. Nakon spajanja Claude čita i djeluje izravno u njima.

  7. #7 Claude Code: pravila dozvola i zaštita lozinki

    Pravila dozvola određuju što Claude Code smije napraviti bez pitanja (allow), kada mora pitati (ask) i što nikad ne smije (deny). Pravila provodi sam Claude Code, pa ih upute u razgovoru ili CLAUDE.md ne mogu zaobići.

  8. #8 Claude Code u VS Codeu

    Proširenje Claude Code za Visual Studio Code daje isti Claude Code u bočnom prozoru, s pregledom izmjena jedna uz drugu i slanjem označenog koda. Treba VS Code 1.94 ili noviji i plaćena Claude pretplata (ili Claude Console račun).

Vodiči su naš sažetak službene dokumentacije: code.claude.com/docs.
