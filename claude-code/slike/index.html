Claude Code: slike i snimke zaslona

Claude Code razumije slike: snimke zaslona s greškom, skice, dijagrame i nacrte stranica. Korisno je kad bi opis riječima bio dug ili nejasan.

1. Tri načina da dodaš sliku

Povuci sliku u prozor Claude Codea. Ili je kopiraj pa zalijepi; na Windowsu je tipka Alt + V (Ctrl + V je za macOS i Linux). Ili napiši putanju do slike.

Alt + V

2. Primjer s putanjom

Upiši putanju do slike na svom računalu:

Analyze this image: C:\Users\<tvoje-ime>\Desktop\greska.png

3. Što ga možeš pitati

Primjeri iz dokumentacije:

What does this image show?
Here's a screenshot of the error. What's causing it?
Generate CSS to match this design mockup

4. Više slika

Zalijepljena slika u poruci postaje oznaka [Image #1], [Image #2]... pa se na nju možeš pozvati po broju. Kad Claude spomene sliku, Ctrl + klik je otvara u pregledniku slika.
