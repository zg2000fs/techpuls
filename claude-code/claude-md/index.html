Claude Code: file CLAUDE.md i naredba /init

Ako Claudeu u svakoj sesiji iznova objašnjavaš kako se gradi tvoj projekt, postoji jednokratno rješenje: file CLAUDE.md.

1. Što je CLAUDE.md

  • Projekt je bilo koji folder u kojem radiš s Claudeom: web stranica, aplikacija, skripte. U CLAUDE.md ide ono što bi inače ponavljao u svakoj sesiji: kako se projekt pokreće i testira (npr. npm test), kako je položen i tvoja pravila (npr. piši na hrvatskom, ne diraj folder dist). Zato ga /init piše umjesto tebe: Claude pregleda projekt i to sam izvuče.
  • To je običan tekstualni dokument u tvom projektu s naredbama za izradu i testiranje, opisom arhitekture i dogovorima o načinu rada. Svaka sljedeća sesija u tom projektu automatski počinje od njega, pa ne moraš svaki put ponavljati iste upute.

2. Stvori ga naredbom /init

Pokreni Claude Code u folderu projekta i upiši naredbu. Claude pregleda projekt i sam napiše početnu verziju filea s naredbama za izradu, uputama za testiranje i dogovorima koje otkrije.

/init

3. Ako file već postoji

Naredba /init u tom slučaju predlaže poboljšanja umjesto da file prepiše.

Želiš li interaktivni tijek koji te dodatno pita što sve postaviti (fileovi CLAUDE.md, skills i hooks) i prikazuje prijedlog prije pisanja, postavi varijablu okruženja prije pokretanja (u PowerShellu):

$env:CLAUDE_CODE_NEW_INIT = "1"
claude

4. Neka bude kratka

Savjet iz Anthropicovih materijala: neka file ne bude dulji od dva ekrana. To je podsjetnik, a ne dokumentacija. Dopuni ga uputama koje Claude sam ne bi otkrio.

5. Uključi druge fileove oznakom @

File možeš uvući u kontekst oznakom @ bilo gdje u CLAUDE.md. Ako putanju želiš samo spomenuti bez uvlačenja, stavi je između obrnutih apostrofa (znak `).

See @README for project overview and @package.json for available npm commands for this project.
