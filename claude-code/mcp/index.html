Claude Code: MCP, spajanje vanjskih alata

MCP (Model Context Protocol) je otvoreni standard koji Claude Code spaja s vanjskim alatima i izvorima podataka, npr. alatima za zadatke, bazama i nadzornim pločama. Nakon spajanja Claude čita i djeluje izravno u njima.

1. Dodaj udaljeni server

Preporučeni prijenos za udaljene servere je HTTP. Sintaksa je claude mcp add --transport http <ime> <adresa>. Primjer za Notion:

claude mcp add --transport http notion https://mcp.notion.com/mcp

Ako server traži token, pošalji ga kao zaglavlje:

claude mcp add --transport http secure-api https://api.example.com/mcp --header "Authorization: Bearer your-token"

2. Popis servera

Iz terminala vidiš sve servere sa statusom (Connected, Needs authentication, Failed to connect):

claude mcp list

3. /mcp unutar sesije

Unutar Claude Codea /mcp prikazuje servere i status te služi za prijavu (OAuth) kod servera koji je traže.

/mcp

4. Gdje vrijedi server (opseg)

local (zadano): samo ti, samo u tom projektu. project: dijeli se s timom preko filea .mcp.json u korijenu projekta (--scope project). user: ti, u svim projektima (--scope user).

5. Oprez

Spajaj samo servere kojima vjeruješ. Server koji dohvaća vanjski sadržaj može podmetnuti upute Claudeu (prompt injection).

Isprobaj Claude: tjedan dana Pro besplatno (partnerska poveznica: ako se preko nje pretplatiš, TechPuls može dobiti nagradu, a tebe to ne košta ništa)
