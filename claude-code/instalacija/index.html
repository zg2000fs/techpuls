Claude Code na Windowsu: instalacija korak po korak

Claude Code je Anthropicov alat koji radi u tekstualnom prozoru (terminalu) i može čitati, mijenjati i pokretati kod u tvom projektu. Ovaj vodič vodi te kroz instalaciju na Windowsu, čak i ako nikad nisi koristio terminal.

1. Što ti treba

  • Windows 10 (verzija 1809 ili novija) ili noviji sustav.
  • Najmanje 4 GB RAM-a i internetska veza.
  • Plaćeni Claude račun: Pro, Max, Ultra, Team, Enterprise ili Console račun. Besplatni claude.ai plan ne uključuje Claude Code.
  • Git for Windows nije obavezan. Ako ga instaliraš, Claude Code ga koristi za neke naredbe; bez njega koristi PowerShell.
Isprobaj Claude: tjedan dana Pro besplatno (partnerska poveznica: ako se preko nje pretplatiš, TechPuls može dobiti nagradu, a tebe to ne košta ništa)

2. Otvori PowerShell

Pritisni tipke Win + X i odaberi Windows PowerShell (ili Terminal). Otvorit će se prozor s trepćućim kursorom: tamo upisuješ naredbe.

Provjeri koji prozor imaš: u PowerShellu redak počinje s PS C:\Users\TvojeIme>, a u CMD-u samo s C:\Users\TvojeIme>. Za sljedeći korak treba ti PowerShell.

3. Instaliraj Claude Code

Kopiraj naredbu gumbom ispod (ili je prepiši) i zalijepi je u PowerShell (Ctrl + V ili desni klik), pa pritisni Enter. Administratorska prava nisu potrebna.

Tijekom preuzimanja ne prikazuje se napredak. Ostavi prozor otvoren dok ne vidiš poruku Claude Code successfully installed!

irm https://claude.ai/install.ps1 | iex

Ako si slučajno u CMD-u, umjesto toga upotrijebi ovu naredbu:

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

4. Pokreni Claude Code i prijavi se

Otvori terminal u folderu svojeg projekta i upiši claude. Pri prvom pokretanju otvorit će se browser u kojem se prijaviš svojim Claude računom. Kad je prijava gotova, vidjet ćeš poruku Login successful.

claude

5. Provjeri da sve radi

Otvori novi prozor PowerShella i provjeri instalaciju. Uspješna instalacija ispisuje broj verzije. Naredba doctor prikazuje dijagnostiku instalacije i postavki.

claude --version
claude doctor

Ako nešto ne radi

Poruka da irm nije prepoznat: otvorio si CMD umjesto PowerShella. Otvori PowerShell (Win + X) ili upotrijebi CMD naredbu iz koraka 3.

Poruka da claude nije prepoznat: zatvori PowerShell, otvori novi prozor i pokušaj ponovno. Ako se ne popravi, dodaj instalacijski folder u PATH ovim naredbama, zatim opet otvori novi prozor:

$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')

SSL/TLS greška na starijem Windowsu 10: prvo pokreni ovaj redak, pa ponovi instalaciju:

[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12

Poruka o 32-bitnom Windowsu na 64-bitnom računalu: otvorio si Windows PowerShell (x86). Otvori onaj bez (x86) u imenu.

Alternative

WinGet: umjesto naredbe iz koraka 3 možeš upotrijebiti Windows upravitelj paketa. Ne ažurira se sam: povremeno pokreni winget upgrade Anthropic.ClaudeCode.

Bez terminala: postoji i Claude aplikacija za Windows koja ne traži terminal.

winget install Anthropic.ClaudeCode

Izvor: code.claude.com/docs/en/terminal-guide, code.claude.com/docs/en/setup. Sadržaj je naš sažetak; ako se dokumentacija promijeni, vrijedi ona.
