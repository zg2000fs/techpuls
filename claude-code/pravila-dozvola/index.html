Claude Code: pravila dozvola i zaštita lozinki

Pravila dozvola određuju što Claude Code smije napraviti bez pitanja (allow), kada mora pitati (ask) i što nikad ne smije (deny). Pravila provodi sam Claude Code, pa ih upute u razgovoru ili CLAUDE.md ne mogu zaobići.

1. /permissions

Unutar Claude Codea /permissions prikazuje sva pravila i iz kojeg settings.json fajla dolazi svako. Tu možeš i dodati ili obrisati pravilo; promjena vrijedi od sljedeće Claudeove radnje.

/permissions

2. Gdje su postavke na Windowsu

Osobne, za sve projekte: C:\Users\<tvoje-ime>\.claude\settings.json. Projektne, dijele se s timom preko gita: <projekt>\.claude\settings.json. Samo tvoje, za jedan projekt (ne ide u git): <projekt>\.claude\settings.local.json. Osobne otvoriš u PowerShellu ovako:

notepad $HOME\.claude\settings.json

3. Primjer: dopusti i zabrani

Primjer iz dokumentacije: dvije naredbe smiju bez pitanja, a fileovi .env (lozinke i ključevi) se ne smiju čitati. Fajl mora biti ispravan JSON: bez komentara i bez zareza iza zadnje stavke.

{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "permissions": {
    "allow": [
      "Bash(npm run lint)",
      "Bash(npm run test *)"
    ],
    "deny": [
      "Read(./.env)",
      "Read(./.env.*)"
    ]
  }
}

4. Kako se pravila pišu

Oblik je Alat ili Alat(točno što). Bash(npm run build) dopušta točno tu naredbu, a * znači bilo što, npr. Bash(git log *). Stavi * iza cijele naredbe: Bash(git *) bi dopustio svaku git naredbu. Read(./.env) se odnosi na čitanje fajla .env, a WebFetch(domain:example.com) na dohvat s te stranice.

Redoslijed je uvijek: deny, pa ask, pa allow. Prvo pravilo koje odgovara odlučuje, pa zabrana pobjeđuje i kad postoji uže dopuštenje.

5. "Da, ne pitaj više"

Kad odobriš naredbu i odabereš da te više ne pita, Claude Code to spremi kao pravilo u .claude\settings.local.json u folderu u kojem si ga pokrenuo (za naredbe trajno, za izmjene fajlova samo do kraja sesije).

Napomena: pravilo Read zabranjuje Claudeovim alatima čitanje tog fajla, ali ne i naredbu koja čita sve fajlove odjednom ili skriptu koja ga sama otvori. Za strožu zaštitu dokumentacija preporučuje sandbox.

Isprobaj Claude: tjedan dana Pro besplatno (partnerska poveznica: ako se preko nje pretplatiš, TechPuls može dobiti nagradu, a tebe to ne košta ništa)
