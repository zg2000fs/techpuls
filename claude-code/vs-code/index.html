Claude Code u VS Codeu

Proširenje Claude Code za Visual Studio Code daje isti Claude Code u bočnom prozoru, s pregledom izmjena jedna uz drugu i slanjem označenog koda. Treba VS Code 1.94 ili noviji i plaćena Claude pretplata (ili Claude Console račun).

1. Instalacija

Pritisni Ctrl + Shift + X, potraži Claude Code (izdavač Anthropic, oznaka anthropic.claude-code) i klikni Install. Ako se ne pojavi, ponovno pokreni VS Code ili u paleti naredbi (Ctrl + Shift + P) odaberi Developer: Reload Window.

Ctrl + Shift + X

2. Otvaranje i prijava

Najbrže: ikona iskre (Spark) gore desno u alatnoj traci uređivača, vidi se kad je otvoren neki fajl. Uvijek dostupno: "✻ Claude Code" dolje desno u statusnoj traci, ili u paleti naredbi upiši Claude Code. Prvi put klikni Sign in i prijavi se u browseru.

Napomena: proširenje ima svoj Claude Code za bočni prozor. Za naredbu claude u terminalu unutar VS Codea treba i samostalna instalacija (prvi video serije).

3. Kako mu pokazati kod

Claude automatski vidi označeni tekst. Alt + K (s fokusom u uređivaču) ubaci oznaku fajla i redaka, npr. @app.ts#5-10. Možeš i upisati @ i dio imena fajla ili foldera. Sliku zalijepiš iz međuspremnika, a fajl dodaš povlačenjem uz držanje tipke Shift.

Alt + K

4. Pregled izmjena

U ručnom načinu Claude prije izmjene prikaže staro i novo jedno do drugog i pita za dopuštenje. Možeš prihvatiti, odbiti ili mu napisati što da napravi drugačije; ispod svake promjene su i gumbi Accept this change i Reject this change.

5. Način rada i plan

Način mijenjaš klikom na oznaku ispod okvira za poruku (Manual, Plan, Edit automatically, a na nekim računima i Auto). U načinu planiranja VS Code otvori plan kao dokument u kojem možeš ostaviti komentare prije nego što Claude krene.
