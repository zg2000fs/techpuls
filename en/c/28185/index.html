Windows 11 runs on a foldable iPhone

An open source project called WindowsiOS runs Windows 11 directly on a foldable iPhone through a virtual machine. It uses touch controls, works in a laptop-style folded mode, and doesn't require jailbreaking the phone.

Windows 11 is now running locally on a foldable iPhone. Google AI Studio's Ammaar Reshi showed an open source project that puts the ARM version of Windows 11 on the phone through a virtual machine, with touch controls and no cloud streaming. Half-fold the device, and it turns into a tiny laptop with a keyboard and touchpad. The phone isn't jailbroken, so you can switch back to normal iOS without losing data.
